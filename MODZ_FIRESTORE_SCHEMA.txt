Modz Web Pro — Firestore structure

users/{uid}
  username: string
  displayName: string
  avatarUrl: string
  bio: string
  friends: array<string>
  online: boolean
  lastSeen: timestamp
  createdAt: timestamp

users/{uid}/bookmarks/{postId}
  postId: string
  createdAt: timestamp

posts/{postId}
  uid: string
  authorName: string
  authorAvatar: string
  content: string
  imageUrl: string
  videoUrl: string
  mediaType: string
  commentsEnabled: boolean
  createdAt: timestamp
  updatedAt: timestamp
  editedAt: timestamp (optional)

posts/{postId}/likes/{uid}
  createdAt: timestamp

posts/{postId}/comments/{commentId}
  uid: string
  authorName: string
  authorAvatar: string
  content: string
  createdAt: timestamp

friendRequests/{requestId}
  from: string
  to: string
  status: pending | accepted | rejected
  fromName: string
  fromUsername: string
  fromAvatar: string
  createdAt: timestamp
  respondedAt: timestamp (optional)

conversations/{conversationId}
  participants: array<string> (2 UIDs)
  participantNames: map
  participantAvatars: map
  lastMessage: string
  lastMessageAt: timestamp
  lastSenderId: string
  unread: map
  typing: map (optional)
  createdAt: timestamp

conversations/{conversationId}/messages/{messageId}
  senderId: string
  text: string
  fileUrl: string
  fileName: string
  fileType: string
  createdAt: timestamp
  readAt: timestamp | null
  editedAt: timestamp | null
  deleted: boolean
  deletedAt: timestamp (optional)
  reactions: map
  replyTo: map | null

notifications/{notificationId}
  uid: string
  type: string
  text: string
  refId: string
  fromUid: string
  createdAt: timestamp
  read: boolean

No Firebase Storage is used by the 4000-line build.
Local image attachments are encoded as Data URLs only when they are small enough for a Firestore document.
Large files/videos should be sent as direct HTTPS URLs.
